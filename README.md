# معجم الطيور: أصواتها، وأشكالها، وصفاتها في العربية

موقع ثابت (HTML + CSS + JS) بدون أي أدوات بناء.

## التشغيل
افتح الفولدر بسيرفر محلي (لأن بعض المتصفحات تمنع الصوت والفيديو من `file://`):

```
python -m http.server 8833
```

ثم افتح `http://localhost:8833`.

## الملفات
- `data/birds.js` — مادة المعجم. كل معلومة `{ t: 'النص', c: [مصادرها] }`.
- `data/sources.js` — المصادر العامة (لسان العرب، المعجم الوسيط، القرآن الكريم).
- `data/media.js` — الصور والأصوات والفيديو من ويكيميديا كومنز مع المؤلف والرخصة.
- `js/app.js` — الترتيب (باب/فصل من الجذر)، الصفحتان، الحواشي، التنزيل PDF.

## إضافة طائر
1. أضف كائنًا جديدًا في `data/birds.js` بنفس شكل الموجود، واكتب الجذر في `root`.
2. أضف وسائطه في `data/media.js` بنفس المفتاح `id`.
3. الترتيب في الأبواب والفصول يصير لحاله.

## التوثيق
- كل جملة لازم يكون معها مصدر في `c`، وإلا ما بتنضاف.
- مقالات ويكيبيديا مربوطة بنسخة ثابتة (`oldid`).
- المصادر الورقية مكتوب فيها المادة بس، وظاهر عليها «يحتاج رقم الجزء والصفحة» لحد ما تنطابق مع طبعة محددة.
