# معجم الطيور: أصواتها، وأشكالها، وصفاتها في العربية

معجم موسوعي موثّق لطيور العالم (11,412 نوعًا)، مرتب على الأبواب والفصول كما في المعجم الوسيط.

- الموقع المنشور: https://bird-lexicon.pages.dev/ (Cloudflare Pages)
- نسخة ثانية: https://hamozalsoud-commits.github.io/bird-lexicon/ (GitHub Pages، بتتحدّث تلقائيًا مع كل push على `main`)
- موقع ثابت: HTML + CSS + JavaScript، بدون أي framework أو أداة بناء.

### النشر على Cloudflare Pages (يدوي)

مشروع Cloudflare مش مربوط بـ git، فبعد أي تعديل لازم تنشر بإيدك (انسخ الملفات اللي بتنعرض بس):

```
mkdir dist && cp -r index.html css js data dist/
npx wrangler pages deploy dist --project-name bird-lexicon --branch main
```

## التشغيل محليًا

لازم يشتغل عبر سيرفر، لأن الموقع بيحمّل ملفات JSON بـ `fetch` (ما بيشتغل كملف `file://`):

```
python -m http.server 8833
```

ثم افتح `http://localhost:8833`.

## هيكل المشروع

```
index.html            الصفحة الوحيدة (أيقونات SVG مشتركة + الشريط العلوي)
css/style.css         كل التنسيق. الألوان والخطوط tokens في أول الملف، مع الوضع الليلي والطباعة
js/app.js             كل المنطق: تحميل البيانات، الترتيب، الصفحات (hash routing)، الحواشي، التنزيل PDF
data/sources.js       المصادر العامة (لسان العرب، المعجم الوسيط، القرآن الكريم)
data/birds.js         المواد المحرَّرة يدويًا (حاليًا 5 طيور) — أغنى مادة: وصف، جذر، اشتقاقات، شواهد
data/media.js         صور وأصوات وفيديو المواد المحرَّرة مع المؤلف والرخصة
data/world/index.json فهرس خفيف لكل الطيور (بيتحمّل أول ما يفتح الموقع)
data/world/fam/*.json ملف لكل فصيلة فيه التفاصيل الكاملة (بيتحمّل عند فتح طائر)
tools/                سكربتات سحب البيانات وتوليد data/world (Python، بدون مكتبات خارجية)
```

## الصفحات (hash routes)

| الرابط | الصفحة |
|---|---|
| `#/` | الرئيسية: البحث والأبواب |
| `#/bab/<حرف>` | باب، مقسّم على فصول |
| `#/families` | كل الفصائل مرتبة على الرتب |
| `#/unnamed` | الطيور بلا اسم عربي موثّق |
| `#/fam/<QID>` | طيور فصيلة واحدة |
| `#/bird/<id>` | صفحتا الطائر (`id` إما معرّف مادة محرَّرة مثل `hudhud` أو QID من ويكيداتا) |
| `#/method` | منهج التوثيق |

## طبقتا البيانات

1. **المواد المحرَّرة** (`data/birds.js`): كل جملة `{ t: 'النص', c: [مصادرها] }`. المصدر إما مفتاح من `sources` الخاصة بالطائر أو مرجع عام عبر الدوال `L()` لسان العرب، `W()` المعجم الوسيط، `Q()` القرآن. الترتيب يُحسب من `root`. لما تنضاف مادة محرَّرة لطائر موجود بالعالم (نفس الاسم العلمي)، بتحل محل صفحته الآلية تلقائيًا.
2. **طيور العالم** (`data/world/`): مولَّدة آليًا من ويكيداتا وويكيبيديا العربية وويكيميديا كومنز. لا تعدّلها يدويًا؛ عدّل السكربتات وأعد التوليد.

### قواعد التوثيق (مهمة)

- ما في معلومة بدون مصدر. ويكيبيديا وويكيداتا مربوطة بنسخة مثبّتة (`oldid`).
- الأسماء العربية مأخوذة من ويكيداتا بس. الطيور بلا اسم عربي ما بنترجم أسماءها.
- المصادر الورقية موثّقة بالمادة، وعليها شارة «يحتاج رقم الجزء والصفحة» لحد ما تنطابق مع طبعة محددة.

## إعادة توليد بيانات العالم

من داخل مجلد `tools/` (الملفات الوسيطة بتنحفظ هناك ومتجاهلة في git):

```
# 1) قائمة كل الأنواع من ويكيداتا (عبر QLever)
curl -sL -m 300 https://qlever.dev/api/wikidata --data-urlencode "query@q.rq" -H "Accept: application/sparql-results+json" -o species.json

# 2) أرقام نسخ ويكيداتا، نصوص ويكيبيديا العربية، بحث عن تسجيلات صوتية، توثيق ملفات كومنز
python enrich.py wd
python enrich.py ar
python enrich.py xc      # الأبطأ (حوالي ساعة)، وبيكمّل من حيث وقف
python enrich.py files   # لازم بعد xc، لأنه بيوثّق ملفات الصوت الجديدة

# 3) توليد data/world
python build.py ../data 2026-10-25   # التاريخ = تاريخ الاطلاع المكتوب بالحواشي
```

- `ROOTS` في `build.py`: جذور الكلمة الأولى من أسماء الطيور الشائعة. أي اسم مش فيها بيترتّب على حروفه.
- `fetch_curated_media.py`: السكربت اللي سحب وسائط الطيور الخمسة المحرَّرة (مرجع، مش جزء من التوليد).

## التنزيل PDF

أزرار التنزيل بتبني نسخة طباعة في `#print-root` وبتفتح نافذة الطباعة (المستخدم يختار «حفظ PDF"). فوق 300 طائر بينزل بدون صور.

## أفكار للمرحلة الجاية

- تحرير المادة اللغوية (جذر، اشتقاقات، ألفاظ صوت) لطيور أكثر في `data/birds.js`.
- مطابقة أرقام الجزء والصفحة للسان العرب والمعجم الوسيط.
- زيادة التسجيلات من xeno-canto (API v3 بدّه مفتاح مجاني، وبعض الرخص غير تجارية).
- ترجمة/كتابة وصف عربي للطيور اللي ما إلها مقالة عربية، مع توثيق.
